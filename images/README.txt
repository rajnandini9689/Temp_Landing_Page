REPLACING PRODUCT PHOTOS
========================

Save your own photo over the file of the same name. Do not rename anything and
do not edit any code.

  hero.png                     opening screen image
  fesubest.png                 FESUBEST - main photo
  fesubest-pack.png            FESUBEST - pack / carton shot
  fesubest-detail.png          FESUBEST - close-up or in-use shot
  naturerise-d3.png            NatureRise-D3 - main photo
  naturerise-d3-pack.png       NatureRise-D3 - pack shot
  naturerise-d3-detail.png     NatureRise-D3 - close-up
  vita-co-gold.png             VITA CO-GOLD - main photo
  vita-co-gold-pack.png        VITA CO-GOLD - pack shot
  vita-co-gold-detail.png      VITA CO-GOLD - close-up
  rn-calci-forte.png           RN-CALCI FORTE - main photo
  rn-calci-forte-pack.png      RN-CALCI FORTE - pack shot
  rn-calci-forte-detail.png    RN-CALCI FORTE - close-up
  rn-omega-1000.png            RN-OMEGA 1000 - main photo
  rn-omega-1000-pack.png       RN-OMEGA 1000 - pack shot
  rn-omega-1000-detail.png     RN-OMEGA 1000 - close-up
  about-lab.png                spare slot for a facility photo
  review-1.png                 reviewer photo

Three rules:

  1. Keep the exact file name, including the .png ending.
     "Fesubest.PNG" or "fesubest.jpg" will NOT be picked up.
  2. Use a square image, around 1200 x 1200 pixels.
  3. Keep each file under about 500 KB.

If a file is missing or misspelt the website draws its own placeholder instead
of showing a broken image, so nothing will ever look broken to a visitor.
